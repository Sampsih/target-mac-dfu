# План развития

## 1.x

- тестирование автоматического DFU на расширенной матрице моделей и кабелей;
- дополнительные автоматические тесты каталогов прошивок.
- проверка переводов носителями языка и дальнейшее улучшение доступности.

## В перспективе

- управляемые корпоративные каталоги IPSW;
- дополнительные проверки состояния Host Mac перед Restore.

Подпись и notarization будут добавлены только после появления сертификата Apple Developer. Это не блокирует развитие функций и интерфейса.

Проект сохраняет однопользовательский сценарий для одного Target Mac. Функции сервисного центра, очереди и массовая обработка устройств не планируются.

Предложения принимаются через GitHub Issues. Порядок пунктов может меняться после тестирования на реальном оборудовании.
