# Target Mac DFU — дизайн macOS 27

Дизайн версии 1.4.0, подготовленный на основе 1.3.0. Это новый интерфейс существующего SwiftUI-приложения, а не заявление о проверке всех API macOS 27. Для компиляции используется установленный SDK 26.5; системные материалы и контролы адаптируются к системе запуска.

## Идея

**Один Mac — одно следующее действие.** Приложение для владельца Mac, а не рабочее место сервисного центра. Главная визуальная точка — силуэт подключённого устройства и подтверждённый статус DFU. Никаких вымышленных процентов успешности, декоративных графиков или анимации «поиска».

Исходный экран повторял действие Restore в двух местах и выделял одинаковыми большими карточками и шаги, и устройство, и подсказку. Новая композиция оставляет одну основную кнопку; выбранная прошивка и загрузка находятся ниже.

## Источник и решения

Использован [dickwu/apple-design-skill](https://github.com/dickwu/apple-design-skill), ревизия `da2da6dd03aacf06da3fecf205347601d38bb141`. Прочитаны инструкции skill и разделы доступности, макета, шрифта, цвета, macOS, материалов, Liquid Glass, боковых панелей и кнопок. Skill использован как справочник без глобальной установки и запуска его скриптов.

- `layout.md › Visual hierarchy`: связанные данные объединены; устройство и действие в одном блоке, прошивки отдельно.
- `buttons.md › Style`: одна акцентная кнопка на главном экране; вторичное скачивание без конкурирующего акцента.
- `materials.md › Liquid Glass`: стекло только в навигации; содержимое на непрозрачных системных поверхностях.
- `sidebars.md › Best practices`: спокойная выбранная строка, настройки рядом с другими разделами.
- `typography.md › Desktop (macOS)`: системные шрифты и их роли; моноширинные данные модели и ECID.
- `accessibility.md › Vision`: цвет дополняется символом и текстом; выбор строки прошивки обозначен для VoiceOver.

## Компоновка

Обычная ширина:

```text
Разделы    Заголовок                              Обновить
           Подключение ─ DFU ─ IPSW ─ Restore
           ┌─────────────────────────────────────────────┐
           │ Mac + статус      Что делать дальше         │
           │ модель · ECID     [Основное действие]       │
           └─────────────────────────────────────────────┘
           Каталог IPSW · выбор прошивки
           Только скачать
```

При недостатке ширины `ViewThatFits` ставит действие под устройством. Полоса шагов остаётся короткой и не имитирует проценты. Минимальное окно приложения сохраняется 1080×690 pt; содержимое прокручивается.

## Проверка замысла

Главный элемент связан именно с DFU: физический Mac и доказанный статус подключения, не универсальная декоративная панель. Удалены большой логотип в навигации, градиент фона и второй основной Restore. Новых анимаций нет; уменьшение движения не лишает пользователя информации. Уменьшение прозрачности имеет непрозрачную навигацию, повышенный контраст усиливает границы.

Полный аудит VoiceOver, клавиатуры и реальный DFU/Restore требуют отдельной проверки на оборудовании. Дизайн не изменяет backend и подтверждения стирания данных.
