# Испытания на реальном оборудовании

Автоматические проверки сборки, моделей состояния и фикстур USB не подтверждают процент успешности физического DFU/Restore. Для версии 1.4.1 новые реальные операции восстановления не выполнялись; обещание успешности 90% не заявляется.

## Как записывать результат

Для каждой попытки укажите версию приложения, модель и macOS Host Mac, модель Target Mac, кабель, используемый DFU-порт, результат входа в DFU и результат Restore. Не публикуйте полный ECID, серийные номера и данные Apple Account. Неудачные попытки тоже учитываются.

| Группа Target Mac | Host macOS | Автоматический DFU | Restore | Статус |
| --- | --- | --- | --- | --- |
| Apple silicon M1/M2 | 14–27 | Проверить | Проверить | Испытания ожидаются |
| Apple silicon M3/M4/M5 | 14–27 | Проверить | Проверить | Испытания ожидаются |
| Intel с T2 | 14–27 | Проверить применимость | Проверить | Испытания ожидаются |

Это план групп испытаний, а не список подтверждённой совместимости каждой модели. Автоматический DFU требует Host Mac с Apple silicon и зависит от поддержки `macvdmtool`; используйте ручной вариант, если команда не сработала.

## Безопасный порядок

1. Используйте только собственный тестовый Target Mac с резервной копией и известной учётной записью владельца. Restore удаляет данные.
2. Проверьте прямое подключение, питание и DFU-порт по [инструкции Apple](https://support.apple.com/en-us/108900).
3. Проверьте автоматический DFU и совпадение модели и ECID. Не повторяйте попытку в ходе активной команды.
4. Перед Restore проверьте блокировку повторных нажатий и штатного выхода. Не проверяйте отказ питания, принудительный сон или обрыв кабеля на ценном устройстве во время стирания.
5. Выполните Restore и проверьте подсказки завершения для соответствующего типа Mac.
6. После успеха или ошибки убедитесь, что настройки разблокировались и временное удержание Host Mac от сна снято.

Потеря подключения, другой ECID, несколько устройств и отказ предварительной проверки покрываются автоматическими фикстурами. Реальные аварийные испытания допускаются только на специально подготовленном оборудовании с согласованным риском потери данных.
