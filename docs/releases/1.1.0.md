# Target Mac DFU 1.1.0

Версия 1.1 делает основной сценарий проще и безопаснее: один последовательный главный экран, более надёжная автоматическая команда DFU, подробная проверка IPSW и понятный прогресс загрузки и Restore.

## Главное

- главный экран показывает четыре шага: подключение, DFU, IPSW и Restore;
- команда DFU автоматически проверяет результат и один раз повторяется при необходимости;
- приложение использует закреплённую ревизию `macvdmtool`;
- IPSW проверяется как ZIP, читается `BuildManifest.plist`, сверяется модель и доступная контрольная сумма;
- перед Restore проверяются Automation Tools, ECID, HTTPS и свободное место;
- загрузка показывает процент, скорость и примерное оставшееся время;
- Restore показывает текущий этап;
- добавлена проверка новых версий через GitHub Releases;
- телеметрия удалена полностью.

## Установка

Скачайте `Target-Mac-DFU-1.1.0.zip`, распакуйте архив и перенесите приложение в `/Applications`.

> Restore полностью удаляет данные на Target Mac. Перед подтверждением ещё раз сверьте модель и последние цифры ECID.
