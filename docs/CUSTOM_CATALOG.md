# Собственный JSON-каталог IPSW

Target Mac DFU может получать список прошивок с внутреннего HTTPS-ресурса или из локального JSON-файла. Это удобно, если IPSW хранятся на своём сервере, NAS или в заранее подготовленной папке.

Готовый шаблон: [`examples/custom-catalog.json`](../examples/custom-catalog.json). Формальная схема для редакторов и валидаторов: [`custom-catalog.schema.json`](custom-catalog.schema.json).

## Рекомендуемый формат

```json
{
  "schemaVersion": 1,
  "devices": [
    {
      "name": "MacBook Pro 14-inch",
      "identifier": "Mac14,7",
      "firmwares": [
        {
          "version": "15.5",
          "build": "24F74",
          "date": "2026-05-20",
          "size": 16543210987,
          "url": "https://firmware.example.com/UniversalMac_15.5_24F74_Restore.ipsw",
          "filename": "UniversalMac_15.5_24F74_Restore.ipsw",
          "sha256": "ЗАМЕНИТЕ_НА_64_ШЕСТНАДЦАТЕРИЧНЫХ_СИМВОЛА",
          "signed": true,
          "beta": false
        }
      ]
    }
  ]
}
```

Для нескольких моделей добавьте отдельный объект в `devices`. Приложение выбирает запись по точному `identifier` обнаруженного Mac.

## Поля прошивки

| Поле | Обязательное | Назначение |
| --- | --- | --- |
| `version` | да | Версия macOS, например `15.5` или `26.0 beta 2`. |
| `build` | да | Номер сборки Apple, например `24F74`. |
| `url` | да | Прямая HTTPS-ссылка на файл `.ipsw`. |
| `signed` | да | Только значение `true` разрешает показать запись. Это декларация каталога, а не обход проверки Apple. |
| `date` | нет | Дата в формате `YYYY-MM-DD`. |
| `size` | нет | Точный размер файла в байтах. Значение `0` отключает сверку размера. |
| `filename` | нет | Имя сохраняемого файла. Если поле отсутствует, имя берётся из URL. |
| `sha256` | рекомендуется | SHA-256 из 64 шестнадцатеричных символов. |
| `sha1` | нет | SHA-1 из 40 символов для каталогов, где SHA-256 отсутствует. |
| `beta` | нет | `true` для beta/RC. Такие записи показываются только при включённых beta-версиях. |

Если указаны обе контрольные суммы, приложение использует SHA-256. После загрузки оно также читает `BuildManifest.plist` внутри IPSW и проверяет совместимость с Model Identifier. Окончательное решение о допустимости Restore всегда принимают инструменты Apple.

## Как подготовить размер и SHA-256

В Terminal на Mac:

```bash
stat -f%z "/путь/к/файлу.ipsw"
shasum -a 256 "/путь/к/файлу.ipsw"
```

Первый результат укажите в `size`, второй — в `sha256`. Нули из файла-примера необходимо заменить реальной контрольной суммой.

## Подключение HTTPS-каталога

1. Разместите JSON и IPSW на HTTPS-сервере с действительным сертификатом.
2. Убедитесь, что URL каталога открывается с Host Mac без авторизации и возвращает сам JSON.
3. В Target Mac DFU откройте **Настройки → Источник IPSW**.
4. Выберите **Собственный HTTPS JSON**.
5. Вставьте полную ссылку, например `https://firmware.example.com/catalog.json`.
6. Нажмите **Применить и обновить каталог**.
7. Переведите Target Mac в DFU. В библиотеке появятся только записи для его точного `identifier`.

Удалённый ответ кэшируется. Если сервер временно недоступен, приложение попробует использовать последнюю успешно полученную копию.

## Подключение локального файла

1. Сохраните каталог с расширением `.json`.
2. Откройте **Настройки → Источник IPSW**.
3. Выберите **Локальный JSON-каталог**.
4. Нажмите **Выбрать JSON…** и укажите файл.
5. Нажмите **Применить и обновить каталог**.

Сам JSON может быть локальным, но `url` каждой прошивки всё равно должен быть прямой HTTPS-ссылкой. Если IPSW уже находится на диске, выберите нужную версию в библиотеке и используйте **Импорт IPSW**.

## Проверка и частые ошибки

- **Список пуст:** проверьте точное совпадение `identifier` и наличие `"signed": true`.
- **Beta не видна:** включите показ beta/RC в настройках.
- **Ошибка безопасной загрузки:** используются только ссылки `https://`.
- **Ошибка размера или SHA:** заново вычислите значения по фактическому IPSW.
- **IPSW не подходит модели:** проверьте `BuildManifest.plist`; перенос записи в другой объект `devices` не делает файл совместимым.
- **Внутренний сервер не открывается:** сертификат должен быть доверен Host Mac, а доступ не должен требовать браузерную сессию, cookie или интерактивный вход.

Перед использованием рабочего каталога рекомендуется сначала проверить его на одном тестовом Mac и сохранить резервную копию JSON.
